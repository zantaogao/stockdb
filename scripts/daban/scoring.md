## 评分公式 (score = base + additions - penalties)

```
base_score = 40  # 首板均值仅+1.42%, 不能再高了

# ── 涨幅 (+0~+25) ──
涨停(>=9.8%):    +25
7-9.8%:          +10~24 (线性插值, 7%=10分, 接近涨停=24分)

# ── 开盘方式 (+0~+20) ──
高开快板(>3%+涨停): +20 ← 回测连板率25.7%, 远高于慢板
小幅高开(1-3%):    +8
低开封板(<-2%):   -5

# ── 换手率 (+0~+20) ──
10-20%(最佳区间): +20 ← 回测连板率45.6%, T+1均值+5.89%
20-35%(次佳):     +12
其他:            +0

# ── 市值 (+0~+20) ──
10-50亿(最佳平衡): +20 ← 连板率31.8%, T+1均值+4.48%
>=200亿(大盘):     +15 ← 收益最高(+5.88%)但样本少
50-200亿:          +8
<3亿(微盘):        +12 ← 高波动, 样本太少(n=25)
3-10亿(最差):      +0

# ── 成交额 (+0~+10) ──
>3亿:              +10
>5000万:           +5

# ── 冲高回落 (-8) ──
high > price*1.03且涨幅>=7%: -8 (盘中模式专用)

max(0, min(100, base+additions)) = final_score
```
