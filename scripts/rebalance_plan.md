# 换仓策略 + 风控执行 改善规划

## 现状

```
评分系统 (combined_score.py, 17:30)
  ↓ 写入 score_history.json
持仓管理 (holdings.json)
  ↓
风控 (agent_risk.py, 每10分钟盘中)
  ↓ 写入 risk_signals.json
执行 (用户手动 or simulate.py 基本买卖)
```

**核心断裂：**
- 评分和持仓之间没有闭环——评分变了，持仓不会自动跟着变
- 风控信号写了，但没人自动执行
- 仓位全靠拍脑袋，没有系统化管理

---

## 一、评分衰减换股（最大收益影响）

**原理：**
评分是最直接的信号——评分从 80 掉到 40 意味着模型认为这只票变差了，应该减仓，而不是等到跌到止损价才卖。

**具体规则：**
```
每周收市后:
  1. 对所有持仓股票按最新 fusion 评分排序
  2. 排名后 20% 且评分 < 50 → 清仓信号
  3. 评分较上周下降 > 15 分 → 减半仓信号
  4. 连续 3 天评分下降 → 警告

每天（盘中）:
  5. 今日评分较昨日下降 > 10 分 → 关注但不操作
```

**输出：** 写入 pending_alerts.json，格式同现有止损信号

---

## 二、止损执行闭环（防风险变实亏）

**现状问题：**
- agent_risk.py 写了 risk_signals.json，但得人去看到才操作
- 收盘后出信号，第二天开盘可能直接跳空穿止损

**改造方案——新增 `risk_executor.py`:**

```
运行时间：盘中 9:30~15:00，每 2 分钟轮询
输入：risk_signals.json, holdings.json, 实时行情
流程：
  1. 读 risk_signals.json 中的 "清仓"/"减半仓" 信号
  2. 如果信号中的股票还在持仓中：
     - 获取当前市价
     - 调用 simulate.py 的 do_sell() 执行
  3. 写入 execution_log（操作记录、成交价、股数）
  4. 更新 holdings.json（减仓/清仓后的仓位）
  5. 告警发 QQ

跳空处理（9:31 开盘检查）:
  - 对比昨日收盘价 vs 今日开盘价
  - 跳空 > 3% 或直接跌穿止损价 → 自动市价减仓
  - 跳空 > 5% → 清仓
```

**执行失败处理：**
- 跌停板无法卖出 → 挂单排队，每分钟重试，直到收盘或成交
- 流动性不足 → 标记为"待处理"，发告警

## 三、仓位管理系统（控风险）

**新增 `position_manager.py`:**

```
输入：holdings.json, score_history.json, 实时行情
运行：每日收市后 + 每次买卖触发时

仓位规则:
  单只上限:  max(20%, 2倍平均仓位)
  单行业上限: 30%
  持仓数量:  8~15 只
  最低现金:  5%
  新开仓下限: 2%（太小没意义）

评分加权仓位:
  总分 = 各持仓评分之和
  目标仓位% = 该票评分 / 总分 * (1 - 现金比例)
  但保留上下限截断

示例（10只票，总分600，现金10%）:
  评分 90 → 目标仓位 90/600*90% = 13.5%  ✓
  评分 30 → 目标仓位 30/600*90% = 4.5%   ✓
  评分 5  → 评分过低，应清仓
```

---

## 四、定期再平衡（保持最优持仓）

**每周一收市后执行：**

```
步骤:
  1. 从 score_history.json 取最新评分
  2. 从 holdings.json 取当前持仓
  3. 取观察池中评分 TOP 15 作为候选
  4. 对比当前持仓 vs 候选排名：
     - 持仓中排名跌出前 15 → 清仓信号
     - 候选前 5 但未持仓 → 买入信号
     - 持仓排名前 5 → 不动
  5. 每次再平衡最多操作 3 只（避免过度交易）
  6. 输出换仓建议 → pending_alerts.json
```

**调仓成本控制：**
```
每次再平衡换手率 ≤ 20%（按金额）
买入时避免追高（偏离5日均线 > 5% → 等回调）
卖出时不恐慌（跌停不卖，等打开再出）
```

## 整体架构

```
              ┌─────────────────────────────┐
              │  评分系统 (17:30 cron)       │
              │  combined_score.py          │
              └──────────┬──────────────────┘
                         ↓ score_history.json
              ┌─────────────────────────────┐
              │  仓位管理 (收市后)            │
              │  position_manager.py        │
              │  - 评分衰减换股              │
              │  - 周度再平衡                │
              │  - 仓位计算                  │
              └──────────┬──────────────────┘
                         ↓ pending_alerts.json
              ┌─────────────────────────────┐
              │  风控 (盘中每10分钟)          │
              │  agent_risk.py              │
              │  - 三层止损                  │
              │  - 大盘调节                   │
              └──────────┬──────────────────┘
                         ↓ risk_signals.json
              ┌─────────────────────────────┐
              │  执行器 (盘中每2分钟)          │
              │  risk_executor.py           │
              │  - 读信号 → 执行买卖          │
              │  - 跳空检测                   │
              │  - 失败重试                   │
              └──────────┬──────────────────┘
                         ↓ simulate.py API
              ┌─────────────────────────────┐
              │  账户 (holdings.json)        │
              └─────────────────────────────┘
```

| 3 | 仓位管理 + 集中度 | 1h | 控风险 |
| 4 | 定期再平衡 | 1h | 保持最优持仓 |
| 5 | 跳空自动执行 | 0.5h | 补漏洞 |
