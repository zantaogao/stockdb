## 功能要求

### LoginPage.ets
- 标题：模拟交易系统
- 输入框：密码（type: InputType.Password）
- 按钮：登录
- 点击按钮 → HTTP POST 到 https://bag-loud-competition-behalf.trycloudflare.com/api/login
- body: {"password": "用户输入"}
- 登录成功 → 保存cookie到AppStorage → 跳转MainPage
- 登录失败 → 提示密码错误

### MainPage.ets
- 全屏 WebView 加载 https://bag-loud-competition-behalf.trycloudflare.com/
- 登录时保存的cookie需要传递给WebView
- 加载前先检查cookie是否有效（调用/api/status）
- 顶部显示加载进度条

### EntryAbility.ets
- 启动即进入 LoginPage

### 网络权限
- 在module.json5中配置网络权限 ohos.permission.INTERNET

## ArkTS 语法要点
- 使用 @State 管理状态
- 使用 http 模块发送网络请求
- 使用 webview 组件
- 使用 AppStorage 持久化存储
