# 10d模型方向准确率评估

评估日期: 2026-07-25

## 核心结论

**reg10_pred与实际10日涨幅呈显著负相关（相关系数-0.59）**

- reg10_pred越高，未来10日超额收益越低（超额收益 = 个股涨幅 - 市场平均）
- reg10_pred越低，未来10日超额收益越高

## 数据验证

样本：1000只股票，reg10_pred来自signal_history的20260723记录
实际涨幅：tushare.db中7/10到7/24的10日收盘价变化

|------|------|

## 对分类用法的指导

reg10_pred反映的是横截面的相对排序（越高表示越"强"），但短期存在动量反转：

1. **高reg10_pred(>=0.10)** → 短期强势但面临回调风险 → 分类为"卖出/持有"
   - 超额收益为负的概率极高（96.3%）

2. **中reg10_pred(0.03~0.10)** → 中等强度，方向不确定
   - 超额收益略负（82.8%概率为负）

3. **低reg10_pred(0~0.03)** → 短期不太强，有上涨空间
   - 超额收益为正的概率66.1%

4. **负reg10_pred(<0)** → 短期偏弱，但反转机会大
   - 超额收益为正的概率84.7%

## 建议

1. 10d分类使用时，**reg10_pred的方向应该反转解释**：
   - 高值 = 可能回调（卖/持）
   - 低值 = 可能上涨（买）

2. 阈值建议：
   - >=+0.10为强卖信号（超额收益-17%）
   - <=0.03为强买信号（超额收益+2.8~3.65%）
   - 0.03~0.10为观望区间

3. reg10_pred与reg20(reg10 vs reg20相关0.18)提供独立的短期信号
