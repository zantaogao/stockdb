# 三个原创因子利用方案

## 一、因子定位

三个新因子与现有reg模型**互补**而非替代：

| 因子 | 与reg10相关性 | 提供的新信息 |
|------|-------------|------------|
| MA_decay (动量衰减) | 0.016 | 独立于reg模型的价格动量衰减信号 |
| flow_alpha (资金流向) | 0.009 | 独立于reg模型的资金流向信号 |
| vol_adj (波动率调整) | 0.161 | 独立于reg模型的波动率标准化信号 |

## 二、具体利用方式

### 1. 信号增强（Signal Boosting）

**原理：** 当reg10给出看涨信号（<0.03）时，如果三个新因子也给出同向信号，增强置信度。

**规则：**
- 强买：reg10 < 0.03 AND (ma_decay > 0 AND flow_alpha > 0 AND vol_adj > 0)
- 买：reg10 < 0.03 AND (ma_decay > 0 OR flow_alpha > 0)
- 强卖：reg10 > 0.03 AND (ma_decay < 0 AND flow_alpha < 0 AND vol_adj < 0)
- 卖：reg10 > 0.03 AND (ma_decay < 0 OR flow_alpha < 0)

**效果：** 提升信号准确率，减少误报。

### 2. 独立选股（Independent Selection）

**原理：** 即使reg10信号不强，如果三个新因子给出强信号，也可以作为独立选股依据。

**规则：**
- 高MA_decay + 高flow_alpha → 动量强劲 + 资金流入 → 短期强势股
- 低vol_adj + 高flow_alpha → 波动率低 + 资金流入 → 稳健增长股
- 高MA_decay + 低vol_adj → 动量强劲 + 波动率低 → 突破股

**效果：** 发现reg模型可能遗漏的标的。

### 3. 风险预警（Risk Warning）

**原理：** 当三个新因子出现背离信号时，提示风险。

**规则：**
- MA_decay < 0 但 flow_alpha > 0 → 动量衰减但资金流入 → 可能止跌
- MA_decay > 0 但 vol_adj < 0 → 动量强劲但波动率异常 → 可能回调
- flow_alpha < 0 但 vol_adj > 0 → 资金流出但波动率正常 → 可能阴跌

**效果：** 提前发现潜在风险，避免追高。

### 4. 融合评分（Fusion Scoring）

**原理：** 将三个新因子与reg模型融合，生成综合评分。

**公式：**
```
fusion_new = 0.3 * reg10 + 0.2 * ma_decay_norm + 0.25 * flow_alpha_norm + 0.25 * vol_adj_norm
```

其中：
- reg10: 直接使用reg10_pred
- ma_decay_norm: ma_decay标准化到[0, 1]
- flow_alpha_norm: flow_alpha标准化到[0, 1]
- vol_adj_norm: vol_adj标准化到[0, 1]

**效果：** 提供单一综合评分，便于排序和筛选。

## 三、实战策略

### 1. 日内交易策略（Intraday）

**规则：**
- 早盘9:30-10:00：扫描MA_decay > 0.5且flow_alpha > 0.2的股票
- 盘中10:00-11:30：监控vol_adj < 0.2且flow_alpha > 0.3的股票
- 尾盘14:30-15:00：选择MA_decay > 0.3且reg10 < 0.03的股票

**效果：** 捕捉日内动量机会。

### 2. 周度调仓策略（Weekly）

**规则：**
- 周五收盘后：计算三个新因子的周度均值
- 下周初：买入MA_decay > 0.5且flow_alpha > 0.3的股票
- 持有5-10天：监控vol_adj，如果vol_adj > 0.5则止盈

**效果：** 捕捉周度动量效应。

### 3. 月度选股策略（Monthly）

**规则：**
- 每月第一个交易日：计算三个新因子的月度排名
- 买入排名前三的股票
- 持有至月末
- 如果vol_adj < 0.3，持有至下月初

**效果：** 捕捉月度动量效应。
